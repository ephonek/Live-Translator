# 直播即時翻譯

將電腦播放的英文／日文語音，辨識並翻譯成繁體中文字幕。

適合觀看 YouTube 直播、影片等內容。目前為 Windows 測試版。

## 功能

- 本機 Qwen3-ASR 語音辨識
- OpenAI API 繁體中文翻譯
- 英文／日文切換
- 無框、置頂字幕視窗，可調整大小與透明度
- 即時原文與翻譯分開顯示
- 可收合的歷史字幕與 token 用量圖表
- 暫停／繼續收音

### 翻譯模式

| 模式 | 處理方式 |
|---|---|
| 兩段合併 | A＋B 一起翻譯，再處理 C＋D；通常較省 API 用量 |
| 逐段滑動 | 參考 B 翻譯 A，再參考 C 翻譯 B；每段都有後文可參考 |

兩種模式都參考前四筆定稿上下文。
等不到後文超過 10 秒，或停止程式時，會翻譯剩餘片段。

## 系統需求

目前安裝器限定：

- Windows x64
- 單張 NVIDIA GeForce RTX 20／30／40／50 系列顯卡
- 至少 8GB 等級顯存
- RTX 20／30／40：NVIDIA 驅動 560.76 或更新（PyTorch 2.14.1＋CUDA 12.6）
- RTX 50：NVIDIA 驅動 580.88 或更新（PyTorch 2.14.1＋CUDA 13.0）
- 網際網路連線
- 自己的 OpenAI API key，以及可用的 API 額度

目前主要在 RTX 3070 Ti 8GB 上測試。
其他符合條件的設備仍需實際驗證。


首次安裝需要下載執行環境、套件及模型，
請預留足夠磁碟空間與下載時間。

## 安裝與啟動

1. 下載專案並解壓縮到可寫入的資料夾。
2. 雙擊 `install.bat`。
3. 等待套件安裝、模型下載及驗證完成。
4. 開啟安裝器建立的 `.env`，填入自己的 API key：

   ```dotenv
   OPENAI_API_KEY=你的實際API金鑰
   ```

5. 雙擊 `start.bat`。
6. 等待模型載入，播放影片或直播。

若 `.env` 尚未建立，可將 `.env.example` 複製並改名為 `.env`。

若 Windows 已設定 `OPENAI_API_KEY` 環境變數，
程式會優先使用環境變數中的值。

### RTX 50 系列安裝

安裝器會自動選擇 `torch==2.14.1+cu130`；20／30／40 系列維持 `cu126`。
共用 requirements 不綁定 CUDA 後綴，避免將 50 系列換回 cu126。
更新程式後請重新執行 `install.bat`，讓安裝器切換套件；不需另裝 CUDA Toolkit。
50 系列尚未完成實機驗證，安裝完成時會檢查套件版本、GPU 運算、SDPA 與模型載入。

只檢查硬體與版本選擇、不安裝任何套件：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -CheckOnly
```

## 使用方式

- `EN / JP`：切換辨識語言。
- `設定`：調整字體、透明度、原文顯示及翻譯模式。
- `字幕`：進入精簡字幕模式，滑鼠移開後隱藏控制列。
- `歷史`：展開或收起歷史字幕。
- `用量`：查看本次執行的 token 累積用量。
- `暫停`：暫停接收新的音訊；已送出的工作仍會完成。
- `停止`：停止擷取並處理剩餘內容。

程式擷取系統播放音訊，其他應用程式的聲音也可能影響辨識。
若收不到聲音，請先確認 terminal 顯示的擷取裝置，
是否與目前播放影片使用的音訊裝置一致。

### 指定程式音訊

在「設定 → 音訊來源」選擇「指定程式」，從清單選 Edge、Chrome 或其他有視窗的程式，再按「套用」。
清單按程序樹分組，瀏覽器同一程序樹中的多個分頁聲音可能一起被擷取；不能分離直播內的背景音樂。
若程式剛開啟，先按「重新整理」。程式關閉／重新啟動後需重新選擇並套用。
來源出錯時會停止該來源並顯示提示，不會自動改抓全部聲音。
可切回「全部輸出」並按「套用」，使用原本的預設輸出裝置擷取。

指定程式功能需要 Windows build 20348 以上（例如 Windows 11）；Windows 10 22H2 不支援，仍可使用全部輸出。
使用 Windows 內建音訊介面，不需另外安裝虛擬音效卡。
更新此版本時，請一併取得 `audio_source.py` 與 `process_audio.py`。

## 費用與隱私

- 音訊由本機模型辨識。
- 辨識文字、翻譯上下文及後文會送至 OpenAI API。
- 翻譯使用自己的 API 額度，會產生費用。
- 畫面的 token 統計不是帳單金額。
- 若請求失敗且未回報用量，會標示用量未知，未包含在總量中。
- `.env` 是明文檔案，請勿上傳 GitHub 或分享給其他人。

程式預設在停止後清理本次字幕紀錄。
這不代表撤回已傳送至 API 的資料。

## 更新

如果使用 Git 下載：

1. 關閉程式。
2. 在專案資料夾執行：

   ```powershell
   git pull --ff-only
   ```

3. 若套件需求有變更，重新執行 `install.bat`。

如果使用 ZIP 下載：

1. 下載新版並解壓縮到新資料夾。
2. 將自己的 `.env` 複製到新版資料夾。
3. 執行 `install.bat`，再執行 `start.bat`。

安裝器不會覆蓋已存在的 `.env`。
建立環境後請避免直接搬動資料夾；換位置時建議重新安裝。

## 已知限制

- 字幕有延遲，不是同步口譯。
- 背景音樂、遊戲語音、多人同時說話及專有名詞可能造成誤辨識。
- 逐段滑動模式需等待下一段，且通常比兩段合併模式使用更多 API 請求。
- ASR 輸出達上限時會拆短重試；仍失敗會略過該段並繼續。
- 長時間使用的穩定性仍在測試中。
